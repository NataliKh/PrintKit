# Листокия — план развития продукта

> Версия плана: 1 ноября 2026 года. Рабочая дорожная карта, а не обещание сроков. Приоритеты можно менять по результатам проверок и обратной связи.

## Цель и принципы

**Цель:** Листокия должна помогать родителю или учителю получить действительно полезный, красивый и корректный материал А4 за 30–60 секунд без регистрации.

- Сначала педагогическая корректность и безупречная печать, затем новые инструменты и привлечение пользователей.
- Работать небольшими независимо проверяемыми релизами.
- Сохранять лёгкую архитектуру HTML/CSS/Vanilla JS, локальную обработку и приватность.
- Визуальная проверка означает просмотр реального вывода (включая экспорт PDF), а не только прохождение тестов.
- Текущий успешный релиз не означает, что все пограничные случаи печати уже проверены.

## Что уже есть (на 01.11.2026)

- Шесть генераторов: математика, карточки, наклейки, грамоты, расписания, привычки.
- Каталог из 25 готовых наборов, отдельные SEO-страницы генераторов, сохранение пользовательских наборов.
- Автоматические тесты логики, создание PDF в Chromium, визуальные артефакты GitHub Actions.
- Яндекс Метрика с загрузкой по согласию пользователя (не подтверждает фактическую физическую печать).
- Исправление маленьких квадратов в математике: на рабочих листах теперь выводится линия для вписывания ответа; коммит `026a2577`.

**Известный риск:** многостраничный вывод основан на ограничениях по количеству элементов; некоторые реальные сочетания контента и размеров всё ещё требуют отдельной визуальной проверки. Не обещать «идеальную печать» до испытаний на бумаге.

### M1 — Качество математики (делаем первым)

**Проблема.** На листе могут подряд встречаться слишком похожие примеры с нулём, одинаковыми числами или почти одинаковыми операциями.

Задачи:
- [x] Проверить `mathGenerate`, определить доступные виды упражнений для каждого класса и стандартных смешанных подборок. Отдельная педагогическая ревизия специальных тем остаётся возможным улучшением.
- [x] Снизить долю тривиальных примеров (`a ± 0`, `a − a`) в **стандартных смешанных листах 1 класса**; для 2–5 классов — отдельная задача.
- [x] Сбалансировать категории и уменьшить повторы в стандартных смешанных заданиях 1 класса («Простые») и 2–5 классов (все уровни).
- [x] Для смешанных листов 1–5 классов предусмотреть конечные наборы кандидатов и безопасный возврат к повторам только при исчерпании вариантов.
- [x] Добавить массовые проверки генераций 1–5 классов: правильность арифметики, целочисленность, диапазоны, уникальность и представленность типов заданий.
- [x] Сохранить действующий регрессионный тест: кнопка «Печать» не создаёт новые задания.

**Критерий готовности:** подборки 10/20/40 заданий корректны; в стандартном смешанном листе из 20 примеров для 1 класса не более 2 заданий типа `a ± 0` или `a − a` при достаточном количестве альтернатив; без необоснованных повторов; существующие тесты и PDF-проверки проходят.

- [ ] Единый PDF / печатный пакет, ответы отдельным блоком в конце.

- [ ] Не выдавать условное «15 минут» за гарантированную продолжительность для любого ребёнка.

**Критерий готовности:** количество занятий, страниц и ключей ответов совпадает; пакет можно распечатать целиком без ручной сборки.

## Правило работы над каждым этапом

1. Перед изменением изучить актуальные `main` и `AGENTS.md`.
2. Выполнить одну ограниченную задачу и написать тесты.
3. Запустить `node --test tests/*.test.mjs` и действующие браузерные проверки PDF.
4. Для печатных изменений просмотреть реальные изображения/PDF. Если ручная визуальная проверка недоступна — указать это.
5. Опубликовать релиз только после успешного GitHub Actions `verify` и `deploy`.
6. После релиза обновить здесь статус/чекбоксы и сообщить: что изменено, что проверено, что осталось.

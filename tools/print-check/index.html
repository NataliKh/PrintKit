ПРОВЕРКА ПЕЧАТИ · А4

Настройте печать до тиража

Сначала распечатайте линейку для проверки масштаба. Затем проверьте совмещение лицевой и оборотной стороны карточек. Для теста достаточно одного листа либо двух страниц в двустороннем режиме.

Что проверяем?

Настройки окна печати

  1. Бумага А4, книжная ориентация.
  2. Масштаб 100% / фактический размер. Отключите «Подогнать под страницу».
  3. Отключите колонтитулы браузера и режим нескольких страниц на листе.
  4. Для калибровки используйте одностороннюю печать.

Подготовлен один лист А4.

Что проверить на бумаге

Линейка должна быть ровно 100 мм, а обе стороны квадрата — 50 мм. Измерьте обычной линейкой.

Проверку фактического смещения может выполнить только человек на распечатанном листе.

Печатный лист

1 лист А4

На экране лист показан для ознакомления. Фактический масштаб оценивайте по бумажному отпечатку.

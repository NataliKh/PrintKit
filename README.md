# Листокия

Бесплатный генератор красивых материалов для печати на А4: упражнения по математике, учебные карточки, именные наклейки, грамоты, расписания и трекеры привычек.

**Сайт:** https://listokia.ru/  
**Репозиторий:** `NataliKh/PrintKit` (историческое имя репозитория; пользователям показывается бренд «Листокия»).

## Запуск

Это статический проект на HTML, CSS и JavaScript, без сервера и передачи личных данных. Откройте `index.html` или запустите `python -m http.server 8000`.

Проверка логики генераторов:

```bash
node --test tests/*.test.mjs
```

## Автоматическая проверка печати и визуальные образцы

В GitHub Actions перед деплоем запускается Chromium. Браузер создаёт реальные PDF, проверяет количество страниц, формат А4, границы элементов и сохранность примеров при печати.

Каждый запуск создаёт **артефакт `printkit-visual`** (на странице соответствующего запуска во вкладке *Summary → Artifacts*). В архиве находятся:

- `index.html` — галерея всех распечатанных страниц, которую можно открыть локально;
- `manifest.json` — машинно-читаемый перечень тестовых сценариев и результатов сравнения;
- `<сценарий>/sample.pdf` — PDF каждого сценария;
- `<сценарий>/page-N.png` — изображения каждой страницы;
- `baseline-page-N.png` и `diff-page-N.png` — исходная и разностная картинки при сравнении.

В pull request workflow пытается загрузить последние сохранённые образцы из `main` и сравнивает их с текущими. Процент изменённых пикселей и картинки-разницы помогают заметить случайные изменения дизайна. **Визуальное различие само по себе не блокирует релиз** (оно может быть ожидаемым после изменения дизайна); ошибки размеров, печатных страниц и переполнения по-прежнему блокируют деплой.

Эталоны создаются автоматически при первом успешном запуске в `main`. При отсутствии подходящего эталона workflow создаёт новые изображения; артефакты хранятся 30 дней.

Для ручного запуска браузерных тестов (нужны Chromium и утилита `pdfinfo`):

```bash
npm install --no-save --no-package-lock playwright@1.56.1 pngjs@7.0.0 pixelmatch@5.3.0
npx playwright install chromium
node tests/print.browser.mjs
```

Отчёт после выполнения: `artifacts/printkit-visual/index.html`. Генерация тестовых снимков использует **вымышленные демонстрационные данные**, а не личные данные пользователей.

## Реальные миниатюры и SEO-страницы

В каталоге используются **снимки реальных листов А4**, а не условные рисунки: каждый из 32 готовых наборов рендерится Chromium с печатными стилями и сохраняется как JPEG. Эти изображения генерируются во время GitHub Actions и передаются в этап публикации как отдельный артефакт `printkit-thumbnails`. Если изображения недоступны при локальном запуске без сборки, интерфейс сохраняет иллюстративный запасной вариант.

Локальная генерация (после установки зависимостей браузерного тестирования):

```bash
node tests/build-previews.mjs
node tests/seo.browser.mjs
```

Шесть статических страниц `tools/<имя>/index.html` имеют собственные заголовки, описания, FAQ и ссылки в редактор с открытым инструментом и набором. Карта сайта: `sitemap.xml`.

**Важно:** публичный адрес сайта — `https://listokia.ru/`, SEO-страницы находятся непосредственно в корне домена. Для индексации отправьте `https://listokia.ru/sitemap.xml` в Google Search Console и Яндекс Вебмастер. Само наличие карты сайта не означает, что страницы уже проиндексированы.

GitHub Pages публикует только файлы из подготовленного каталога `_site` — без `node_modules`, тестов и промежуточных PDF.

## Математика по классам и темам

В генераторе математики класс определяет доступные темы. Режим «По программе класса» смешивает темы соответствующего класса; можно выбрать одну конкретную тему:

- 1 класс — сложение, вычитание, пропущенное число.
- 2 класс — переход через десяток и задания с пропущенным числом.
- 3 класс — таблица умножения и деление без остатка.
- 4 класс — умножение, деление и порядок действий.
- 5 класс — доли числа, умножение, деление и порядок действий.

Поле «Сложение и вычитание: тип» влияет на задания с этими действиями. Все результаты целые, неотрицательные и не превышают выбранный максимум; для младших классов дополнительно действует возрастное ограничение диапазона (1 класс — до 20, 2–3 классы — до 100). Для математики сохраняется отдельный лист с ответами, а печать не регенерирует задания. При узком диапазоне и большом числе заданий отдельные выражения могут повторяться.

## Карточки 2.0: проверка перед печатью

Поддерживаются размеры А4 4 / 8 / 12 карточек и двусторонняя печать с переворотом по длинному или короткому краю. В каталоге есть школьные наборы «Времена года», «Школьные принадлежности» и «Природа вокруг нас». В редакторе каждый непустой ряд должен содержать пару \`термин — перевод\`. Пустой список, строки без перевода и тексты сверх безопасных символьных ограничений выбранного размера блокируют кнопку печати, показывая номер проблемной строки; более крупный размер может помочь. Дополнительно браузер проверяет фактическое переполнение. Данные остаются локальными. Символьные пределы — защитная эвристика, не замена просмотру PDF; физическое совмещение сторон пока не проверено.

## Адаптивная печать расписаний на A4

Для расписания при длинных названиях уроков редактор автоматически распределяет **целые строки** по листам A4 на основе фактических размеров таблицы в браузере. Обычные короткие строки по-прежнему собираются по восемь на лист. Если один урок настолько длинный, что строка не помещается на странице, кнопка печати блокируется и появляется объяснение. Перед печатью также завершается ещё не применённый ввод, поэтому PDF не должен содержать старую версию только что исправленного текста. Физический принтер и Firefox отдельно не проверены, универсальная пагинация остальных инструментов остаётся задачей.

## «Мои наборы» — локальные сохранённые проекты

В редакторе откройте раздел **«Мои наборы»**, введите название и нажмите **«Сохранить»**. Можно хранить до **12 наборов** одновременно и открывать их независимо от текущего генератора. Сохраняются **настройки и введённые поля**, включая имена, текст, размеры и оформление. Для математических упражнений при повторном открытии генерируются **новые примеры**, а не прежний случайный лист.

У каждого набора есть кнопки **«Открыть»** и **«Удалить»**; удаление требует подтверждения. Наборы хранятся в `localStorage` только на текущем устройстве и в текущем браузере (`printkit.saved.v1`, ключ сохранён ради совместимости). **Это не облачное сохранение**: данные старого адреса `natalikh.github.io` не переносятся автоматически на `listokia.ru`; очистка данных сайта, приватный режим или переход на другой браузер могут привести к их потере. Никакие данные наборов не добавляются к URL, не отправляются на сервер и не входят в тестовые PDF-артефакты.

Браузерные проверки проверяют сохранение и открытие между вкладками генератора, перезагрузку страницы, подтверждение удаления, экранирование имён наборов и мобильную вёрстку. Node-тесты охватывают формат записей, лимит, повреждённое хранилище и ошибки квоты.

## Школьный комплект наклеек

В генераторе «Наклейки» выберите **«Школьный комплект»** либо одноимённый готовый набор. Имя вводится один раз, а список предметов позволяет включать или отключать каждый предмет и указывать от 1 до 24 наклеек для него. Можно добавить свой предмет (до 20 записей), удалять строки и менять количество. Общий лимит — 96 наклеек за один комплект, печать при превышении лимита или пустом выборе блокируется. Доступны все три физических размера и четыре темы. Список предметов и количества сохраняются в «Мои наборы» локально в браузере.

## Наклейки сразу для нескольких детей

В разделе «Наклейки» доступно поле **«Для кого» → «Несколько детей»**. Введите до **6 имён** (каждое с новой строки); первое имя автоматически переносится из одиночного режима при первом переключении. Выбранный размер, оформление и подпись применяются к каждому ребёнку. В «Школьном комплекте» каждому ребёнку печатается одинаковый набор выбранных предметов с заданными количествами. Например, два ребёнка × 12 предметных наклеек = 24 наклейки, распределённые по листам А4 в порядке имён.

В предпросмотре и перед печатью действует общий предел **96 наклеек за один раз**. Печать блокируется при пустом списке, более чем 6 именах, слишком длинных именах или превышении лимита. «Мои наборы» сохраняют список имён только локально в текущем браузере; никаких данных детей на сервер не отправляется.



### Кросс-браузерная проверка печати

GitHub Actions запускает `tests/print.browser.mjs` (реальные PDF из Chromium) и `tests/firefox.browser.mjs` (независимые замеры А4 с `@media print` в Firefox/Chromium). Скриншоты первых листов и отчёт `comparison.json` сохраняются в артефакте `printkit-firefox-print`. Для запуска локально: `npx playwright install chromium firefox`, затем `node tests/firefox.browser.mjs`. Playwright не создаёт PDF с помощью Firefox; физическая двусторонняя печать тоже требует отдельного теста.


## Контрольная проверка домашнего принтера (P0.5)

Страница `https://listokia.ru/tools/print-check/` содержит два независимых режима: линейка 100 мм + квадрат 50 × 50 мм для односторонней калибровки и парные листы лицевой/оборотной стороны карточек (4, 8, 12 на A4) для проверки двух вариантов переворота. Печатайте на A4 книжной ориентации, масштаб 100% («Фактический размер»), без «Подогнать», колонтитулов и режима нескольких страниц на листе. После пробной двусторонней печати проверьте на просвет совпадение номеров и рамок. Реальное совмещение пока не проверено на принтере.

Браузерные тесты `tests/print-check.browser.mjs` проходят в Chromium и Firefox; реальный PDF генерируется только из Chromium. Контрольная раскладка повторно использует исходный `renderSheet('cards')`.


## P0.5.1 — измерение физической печати

На `/tools/print-check/` четыре одинаковых контрольных крестика в углах **каждой** стороны теста двусторонних карточек. Их центры отступают на 13 мм от края А4, в пределах свободного поля печатного листа. На реальном отпечатке совместите две стороны на просвет и измерьте смещение центров крестиков по горизонтали и вертикали. В форме на странице можно ввести результаты и увидеть подсказку; значения не сохраняются и не отправляются на сервер. Для масштаба предусмотрены три поля — линия 100 мм, ширина и высота квадрата 50 мм. Порог ±1 мм в подсказках — удобный пользовательский ориентир, не гарантированный допуск принтера.

## M5.1 — математические комплекты (04.11.2026)

В инструменте «Математика» есть выбор одного обычного листа либо печатного комплекта на **5, 10 или 20 занятий**. Пользователь задаёт класс, тему, количество заданий на занятие, размер шрифта и максимальный результат. Каждое занятие начинается с нового листа A4 (большое занятие может занять несколько страниц), а задания нумеруются заново. Ответы при включённом ключе собраны **в конце всего комплекта**, отдельная страница на занятие. Все занятия и ответы печатаются одной командой «Распечатать / PDF».

Начальные занятия используют более простой диапазон и допустимый тип упражнений, позже материал становится сложнее в пределах выбранных настроек. Смена плотности и показ/скрытие ответов не пересоздают примеры; кнопка «Новые примеры» создаёт другой комплект. Длительность занятия индивидуальна, обещания «ровно 15 минут» нет. Сохранённые настройки остаются локально в браузере.
